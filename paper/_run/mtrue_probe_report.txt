探针④ · 隐态天花板 + 校准辅助头对照（未压缩数据方向系统性排查）
=======================================================================
目标：把 oracle(0.762) 与 可提取(≈0.72) 之间的 gap① 分解为
  特征提取不足 / 容量不足 / 监督(校准)不足 / 表示固有上限。

统一设置：同一 test 切分(training/data/p0_prereq.split.json，fixed)、num_topics=192/max_len=16、seed=0。
上界 oracle(pOk) = 0.7619（p0_prereq 与 mtrue_probe 一致）。

一、特征注入（真隐藏态 m_t 作为输入，探针④a）
  数据 mtrue_probe.jsonl：与 p0_prereq 同配置生成、3840 行逐行同序，pres 通道覆写为"作答前真掌握度 m_t"。
  基线(可观察)              DKT auc=0.7189
  + m_t 注入(h32/e16)       DKT auc=0.7184   → 不升反微降
  + m_t +大容量(h256/e64/attn) auc=0.7200    → 容量也抬不动

二、容量放大（无特征注入，对照特征 vs 容量根源）
  h256/e64/attn（论文容量扫描 c4 同量级）≈0.71，与 h32 的 0.7189 相当 → 非容量瓶颈 ① 已证。

三、校准辅助头 (探针④c)：监督同一读出头直接拟合真概率 pOk[t+1]
  思路：若 gap 是"监督没教对"，则给共享隐态加一个被 pOk 直接监督的校准头，其 AUC 应逼近 oracle。
  + 单线性 calib 头：calib auc=0.7143（next 0.7156）
  + 两层 MLP calib 头：calib auc=0.7235（next 0.7204）  ← 最强读数，仍远低于 oracle
  （calib_net 仅在 --use-pok-calib 时构建，部署 ONNX 仍 3 输出，无回归）

四、汇总读数
  配置                                   AUC
  oracle (pOk, 真单元条件概率排序)        0.7619
  DKT 基线(可观察)                        0.7189
  + 真隐藏态 m_t 注入                     0.7184
  + m_t + 大容量+attn                       0.7200
  + 线性 calib 头(监督 pOk)                0.7143
  + MLP  calib 头(监督 pOk)                0.7235

五、结论（④ 未压缩方向，系统性收敛）
  ◆ 无论"注入真隐藏特征 / 放大容量 / 直接监督头去拟合真概率 pOk"，模型 AUC 全部封顶在 ≈0.72
    （最强 0.7235，与 oracle 0.7619 相差 ≈0.038）。
  ◆ gap① 不是"可观察特征提取不足"，也不是"容量不足"，也不是"监督/校准方法不到位"，
    而是 GRU 学得表示(隐含状态 h_t)对"逐(状态,难度)真条件概率 pOk 的排序"的固有复现上限：
    oracle 只有拿"真概率本身"当打分器才达到，任何有限学得表示都投影到更粗的分。
  ◆ 论文三层框架含义（需修正措辞）：
    - "可观察可提取上界 Ⅱ≈0.71-0.72"对 特征/容量/校准监督 三重封顶，是稳健的模型侧平台。
    - 原"gap① 为不可观察隐藏信息"措辞宜改为更准确表述：
      "Ⅱ 到 Ⅰ 的残差是'有限学得表示对逐单元校准概率排序的不可逼近残差'（可观察但不可由
       该表示复现），而非'数据中不存在可提取信息'（数据内 oracle 信息存在=0.762）。"
  ◆ 实践含义：堆特征/堆容量/堆校准都在相同数据与表示类型下封顶；要抬模型(不靠 oracle 作弊)
    需换表示归纳偏置（逐单元难度-概率校准建模），或走 ③ 真实数据(难度已贯通)论证可迁移性。

六、稳健性（多 seed 取 mean±std，同一 fixed 切分）
  配置            seed0   seed1   seed2    mean±std
  基线 DKT        0.7189  0.7192  0.7191   0.7191±0.0002
  MLP calib 头    0.7235  0.7236  0.7194   0.7222±0.0024
  oracle(pOk)                           = 0.7619（与数据无关，恒定）
  → 校准头在 3 seeds 上稳定高于基线 ≈0.003，但两者均封顶于 ≈0.72 平台，
    与 oracle 差距 ≈0.040 稳定存在；校准头的 seed 波动(±0.0024)不足以覆盖该 gap。
  → 多 seed 复核了 §五 结论：gap① 非"监督/校准不到位"，而是有限学得表示对
    "逐(状态,难度)真概率 pOk 排序"的固有复现上限。

七、跨数据对照成熟度检查：报告待办状态迁移到 §八 之后，原文待办作废——
  但保留【结论修正】作为最重要产出：
  ◆【重要修正】"gap① = 表示固有上限"这一归因，仅在被"本项目自研模拟器"这一
    单一数据分布误导时成立。§八 跨数据对照显示：
      · 同一 DKT 模型在第三方合成(ktbd synthetic)上能到 0.815；
      · 在 Junyi 真实数据上 0.802；在 ASSIST09 上 0.675。
    即"0.72 平台"是【本项目生成分布的固有可预测瓶颈】，不是模型通用上限。
    模型上限随数据集可榨取上限浮动；每数据集的 oracle 决定其绝对极限。

八、跨数据集对照 + 文献上界标定（③真实/跨生成分布方向，交叉验证 §五 结论）
  ---------------------------------------------------------------------
  8.1 自测跨数据集中读数（同一 DKT 管线，train_dkt.py，fixed 切分、early stop）
    数据源              类型      知识点   DKT AUC(mean±std)      BKT
    -----------------------------------------------------------------
    本项目自研模拟器     自研合成    192    0.7191±0.0002(3seed)  0.678(可观察)
    ktbd synthetic     第三方合成    50     0.815 ±0.001 (3seed) 0.730     ← 关键对照
    JunyiAcademy       真实数学     835    0.8020±0.0001(3seed)  0.758
       (0.8019/0.8022/0.8021)
    ASSISTments2009    真实数学     146    0.675±0.0006         0.640
    文献同口径 ASSIST09 DKT≈0.748（见 §8.2 综述，实现差异导致）
  -----------------------------------------------------------------
  ◆ 最重要事实：ktbd synthetic 0.815 >> 本项目自研 0.719。两者都是"可观测合成
    数据"，却差 ~0.09。据此**推翻 §五 的"GRU 表示固有上限"归因**：
    0.72 是【本项目模拟器生成分布自带的低可预测性】，非模型可提取的通用封顶。
  ◆ 自研 oracle(pOk)=0.762，模型 0.719 ≈ oracle 的 94% —— 说明模型已基本榨干
    该数据，剩余 gap 是数据自身的不可确定信息，而非容量/特征/校准不足。

  8.2 文献基准：合成数据上界标定（"合成数据最高能榨到多少"）
    Synthetic-5(IRT 生成，50题/5技能，Piech DKT 原生成器)——KT 最标准合成基准
      模型        AUC      出处
      SKVMN       0.84±0.04 Zaki/SKVMN
      DKVMN       0.827±0.1 Zhang et al., WWW'17
      MANN        0.81     Zhang et al., WWW'17
      DKT         0.80-0.81 Piech 2015 & 复现
      DKT(另复现) 0.7506   王忠 2024 HRGKT  ← 同数据不同实现差异 ~0.05-0.09
      BKT         0.62
    其他含合成成分数据：
      ES-KT-24(真实游戏+合成题文) SimpleKT 0.7366 最高 → 多源噪声拉低
      KTBench 跨7数据集均值     KQN 0.7993 最高（含真实，非纯合成）
  ◆ 结论：**0.84(SKVMN/Synthetic-5) 为文献合成数据当前最高上界**。
    Synthetic-5 是唯一被反复用作"高可预测合成基准"的数据；未发现更高合成纪录。
  ◆ 警告：同数据不同预处理/实现的 DKT 可从 0.80 掉到 0.75，上界对预处理+模型+
    早停极度敏感；引用必须并列表述差异，避免读者误以为同数据必须同 AUC。

  8.3 交叉验证 → 论文分层框架（修正 §五 措辞后的正式归因）
    数据极限上界（Ⅰ）    由数据生成机制决定：本项目 0.762；Synthetic-5 型 ~0.84。
    模型可榨取上限（Ⅱ）  随数据集浮动：本项目 0.719(94% of Ⅰ)；synthetic 0.815。
    跨数据差异  >>  单数据榨干：换高可预测分布(0.815)收益远大于在当前数据上调模型。
  ◆ 对算法价值：合成数据上界 ~0.84 是"规律性边界"，非无限；要抬 gAp 的真正杠杆
    是数据生成分布（③真实数据/更规律合成），而非在既有分布上堆容量/特征/校准头。
